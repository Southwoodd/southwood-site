# Страницы

Сейчас на сайте работает только заглушка: `index.astro` и `404.astro`.

Старые страницы в черно-желтом дизайне отключены, но не удалены. Astro не собирает
файлы и папки, имя которых начинается с подчеркивания:

- `_cases/[slug].astro` — страницы кейсов
- `_privacy.astro` — политика конфиденциальности
- `_ui.astro` — служебная библиотека компонентов

Чтобы вернуть страницу, уберите подчеркивание из имени.
