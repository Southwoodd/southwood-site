# Прием заявок на Cloudflare Workers

Замена `server/lead-server.mjs`. Отличия от прежнего сервера:

- заявки нигде не хранятся, уходят только в Telegram и на почту;
- PDF расчета уходит в Telegram вложением прямо из памяти и нигде не сохраняется;
- в письмо идет состав расчета текстом и ссылка на расчет: по ней он открывается на сайте таким же,
  каким его собрал посетитель, с кнопкой «Скачать расчет в PDF» — файл в письме не нужен;
- очереди повторной отправки, счетчики блога и защита от повторов живут в D1;
- вместо `setInterval` расписание Cloudflare: разбор очереди раз в минуту, уборка раз в шесть часов.

Почта по-прежнему уходит своим SMTP с порта 465. Порт 25 из воркера закрыт, 465 разрешен.

Хранилище R2 не используется: включать его в панели Cloudflare не нужно.

## Адреса

| Адрес | Что делает |
| --- | --- |
| `POST /lead` | заявка и сообщение с сайта |
| `GET /stat?p=<статья>` | счетчики статьи |
| `POST /stat` | отметка «дочитал» или «поделился» |
| `GET /health` | длина обеих очередей |

## Что уходит в Telegram и в письмо

| Случай | Telegram | Письмо |
| --- | --- | --- |
| Заявка без расчета | все поля | все поля |
| Расчет без файла | поля и состав расчета | поля, состав расчета, ссылка |
| Расчет с файлом | поля и PDF вложением, состав не дублируется | поля, состав расчета, ссылка |
| Канал не ответил | из очереди уходит вид с составом, без файла | из очереди уходит то же письмо |

## Локально

```bash
cd worker
npm install
npx wrangler d1 execute southwood-lead --local --file schema.sql -y
npx wrangler dev --local --port 8799
```

В другом окне:

```bash
node test-build.mjs   # разбор заявки, 18 проверок
node test-http.mjs    # адреса, 16 проверок
```

Без секретов оба канала отваливаются, и заявка ложится в очередь: так и задумано, это проверка очереди.
Перед повторным прогоном почистить `hits`, иначе упрется в ограничение частоты:

```bash
npx wrangler d1 execute southwood-lead --local -y --command 'delete from hits; delete from queue; delete from seen; delete from stats'
```

## Разворачивание

База уже создана, ее идентификатор вписан в `wrangler.toml`. Остается схема, секреты и выкладка:

```bash
npx wrangler d1 execute southwood-lead --remote --file schema.sql -y
npx wrangler secret put TG_BOT_TOKEN   # и так же остальные пять
npx wrangler deploy
```

Секреты: `TG_BOT_TOKEN`, `TG_CHAT_ID`, `SMTP_HOST`, `SMTP_USER`, `SMTP_PASS`, `MAIL_TO`.
Значения те же, что в `/etc/southwood/form.env` на прежнем сервере.

## Что поменять в сайте при переключении

- `src/i18n/ru.ts` — адрес приема заявок;
- `src/pages/blog/[...slug].astro` — адрес счетчиков;
- счетчики из `stats.json` с прежнего сервера перенести в таблицу `stats`, иначе числа обнулятся.
